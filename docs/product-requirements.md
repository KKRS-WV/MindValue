# MindVault V1 Product Requirements

MindVault is a graph-first personal knowledge management system. Its core hypothesis is that users may prefer a knowledge map over a traditional tree directory for managing personal knowledge.

## V1 Includes

- Knowledge base management.
- Node management with unlimited hierarchy.
- One Markdown document per node.
- Dynamic graph browsing.
- Global search across nodes and documents.

## V1 Excludes

- AI Q&A.
- RAG.
- Vector database.
- OpenAI integration.
- OCR.
- PDF parsing.
- Team collaboration.
- Permission management beyond authenticated ownership.
- Share links.
- Notifications.
- Microservices.
- Redis.
- Elasticsearch.

## Product Principle

The knowledge map is the first entry point. Documents are the second entry point. New functionality must not turn the product into a traditional tree-first knowledge base.
